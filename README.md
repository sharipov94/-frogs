## 2. Назначение проекта

Бот предназначен для:

-   отображения каталога товаров
-   просмотра карточки товара
-   отправки заявки на заказ
-   администрирования каталога (добавление, редактирование, скрытие)
-   управления статусом товара (в наличии / распродано)

Проект реализует магазин внутри Telegram с inline-интерфейсом без спама
сообщений.

## 5. Архитектурный подход

Проект построен по принципу:

-   Разделение логики (handlers / services / db)
-   Репозиторий как слой доступа к данным
-   FSM для добавления и редактирования товаров
-   Inline UI для минимизации спама сообщений
-   Soft delete через поле `is_hidden`

------------------------------------------------------------------------

## 6. База данных

### Таблица `products`

  Поле           Тип       Назначение
  -------------- --------- -----------------------------
  id             INTEGER   ID товара
  slug           TEXT      Уникальный идентификатор
  title          TEXT      Название
  description    TEXT      Описание
  price          INTEGER   Цена
  currency       TEXT      Валюта
  status         TEXT      available / reserved / sold
  status_label   TEXT      Текст статуса
  is_hidden      INTEGER   0 = видно, 1 = скрыто
  created_at     TEXT      Дата создания

------------------------------------------------------------------------

### Таблица `product_photos`

Хранит Telegram file_id фотографий.

------------------------------------------------------------------------

### Таблица `orders_requests`

Хранит заявки пользователей.
